# Desktop application support

Phase 5 targets Windows provisionally. Support is limited to tested workflows. The visible interactive session is required for input actions.

| Application                | Version/date                              | Workflow                                                                                                  | Backend                   | Status     | Limit                                                                                                 |
| -------------------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------- | ---------- | ----------------------------------------------------------------------------------------------------- |
| Synthetic WinForms fixture | .NET 9, 2026-10-23                        | launch, inspect, focus, literal text, button state, window screenshot, wrong-window block, movement block | UIA/Win32                 | VERIFIED   | Fixture exercises the adapter, not third-party app compatibility.                                     |
| VS Code                    | 1.140.0, 2026-10-23                       | launch new window with approved fixture workspace and known file; title and foreground observed           | CLI template + UIA window | PARTIAL    | Editor typing/saving and full worker dispatch not verified. Integrated terminal input is unsupported. |
| Windows Character Map      | 5.2.3668.0, 2026-10-23                    | open fresh window, enable Advanced view, enter bounded search text, inspect selected character            | UIA + native typing       | PARTIAL    | The selected character was also present before search, so Search effect is not independently proven.  |
| Windows Notepad            | packaged 11.2607.14.0 observed 2026-10-23 | System32 launcher to app window                                                                           | UIA attempt               | BLOCKED    | Packaged process identity differs from launcher. An existing unsaved owner document was not touched.  |
| Other Windows apps         | —                                         | —                                                                                                         | —                         | UNVERIFIED | Require local owner approval and a declared tested workflow.                                          |

The helper allows text only in the synthetic fixture, approved Notepad edit controls, and Character Map's `Search for` field. It allows clicks only on the fixture's `Update status` button and Character Map's `Advanced view`/`Search` controls; all other clicks fail closed pending app-specific classification and approval binding. No coordinate-based visual click is implemented.
